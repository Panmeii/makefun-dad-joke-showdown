Dad Joke Showdown — one dad joke, at most 200 characters, written to be told out loud at the dinner table: a straight-faced question to a dog whose answer is a clean arithmetic pun, with the groan saved for the very last word. The Node program (`main.ts`) writes the joke to `entry.txt` in the output directory and verifies the delivered file against the competition gate (UTF-8, 1–200 characters, single line, punchline at the end) before reporting success.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
